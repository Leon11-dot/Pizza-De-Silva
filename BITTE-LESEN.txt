PIZZA DE SILVA ADMIN – ECHTE ANDROID-APP

Diese Version ist als echte Android-App vorbereitet.

Schon eingebaut:
- Name: Pizza De Silva Admin
- öffnet direkt https://www.pizzadesilva.de/admin.html
- eigenes App-Symbol
- Android-Benachrichtigungskanal „Neue Bestellungen“
- eigener Pizza-De-Silva-Alarmton pds_alarm.wav
- starke Vibration
- FCM/Firebase-Push-Unterstützung vorbereitet
- GitHub-Actions-Datei, die automatisch eine APK baut

WICHTIG:
Für echte Push-Benachrichtigungen bei komplett geschlossener App fehlen noch die 4 Firebase-Werte
(API Key, App ID, Project ID, Sender ID) und der Firebase-Serverzugang.
Ohne diese Werte kann die App bereits gebaut/installiert werden und die Adminseite öffnen,
aber Push bei komplett geschlossener App ist noch nicht aktiv.

APK über GitHub bauen:
1. Projektdateien in ein GitHub-Repository hochladen.
2. GitHub → Actions → „Build Pizza De Silva Admin APK“.
3. „Run workflow“ anklicken.
4. Nach dem Build unten „Pizza-De-Silva-Admin-APK“ herunterladen.
5. Darin liegt app-debug.apk.
6. APK auf dem Redmi installieren.

Der Server-Ordner „supabase“ enthält die vorbereitete Registrierung für Android-Push.
